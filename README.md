## Project Overview

This project explores air quality trends across Indian cities using Python and data analysis techniques. It examines Air Quality Index (AQI) values, pollution patterns, missing data, yearly changes, and relationships between pollutants and AQI.

The goal is to transform air quality data into meaningful insights through data cleaning, exploratory data analysis (EDA), statistical summaries, and visualization.

## Objectives

- Inspect and understand the air quality dataset.
- Identify and summarize missing values.
- Analyze AQI categories and city-level pollution patterns.
- Explore monthly and yearly AQI trends.
- Compare a consistent group of cities across multiple years.
- Investigate correlations between pollutants and AQI.
- Present findings through charts, tables, and a project report.

## Key Findings

The analysis produced the following descriptive findings:

- Ahmedabad had the highest average AQI among the cities in the dataset, at approximately 452.12.
- Delhi had an average AQI of approximately 259.49.
- Moderate and Satisfactory were the most frequent AQI categories among records with available AQI values.
- PM10 showed a strong positive correlation with AQI in the analyzed data (approximately 0.80).
- PM2.5 and CO also showed positive correlations with AQI.
- A comparison of the same seven cities from 2015 to 2019 showed variation in yearly average AQI, with the 2019 average approximately 6.8% below the 2015 average.

These are descriptive results from the available dataset, not proof of causation or evidence that air quality improved uniformly across India. Data coverage varies by year, and 2020 contains only partial-year observations.
