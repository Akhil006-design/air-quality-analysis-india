# Task 1: Python Basics

## Project
Air Quality Analysis in India

## Objective
Practice fundamental Python concepts using air quality information from Indian cities and establish a programming foundation for subsequent data analysis.

## Concepts Covered
- Variables and data types (strings, floats, lists, dictionaries)
- Printing formatted output
- Conditional statements (`if`, `elif`, `else`) for AQI classification
- Lists and loops (`for` loops and iteration)
- Dictionaries (key-value lookups for city AQI data)
- Functions (reusable assessment logic)
- Arithmetic calculations and average calculation
- Comparing AQI values across cities

## Tools Used
- Python (`.venv` virtual environment)
- Antigravity IDE
- PowerShell terminal

## Program Structure
The file [task1_python_basics.py](file:///c:/Antigravity/Next_gen/tasks/Task_1_Python_Basics/task1_python_basics.py) demonstrates core Python basics using sample AQI values for Delhi, Patna, and Lucknow.

Run the script from the project root using:
